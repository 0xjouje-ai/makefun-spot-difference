Twin Lanterns — a spot-the-difference game with three original lantern-lit scenes (a harbour at dusk, a lantern garden, a night market), seven hidden differences per scene, a three-minute timer, hints, combos and synthesized sound, all drawn and played offline in the browser.

## Run it

```sh
node game/serve.js
```

Then open http://localhost:8080 in a desktop browser. Or serve `game/` with any static file server and open `index.html` — the game makes no network requests.
